Отчёт по модулю В. Обработка транспортных данных

Цель работы: обработать данные транспортных детекторов, сформировать временные показатели и выполнить их пространственную привязку к транспортному графу.

Выполненные работы: данные детекторов очищены и преобразованы с использованием Python и Pandas. Рассчитаны временные агрегаты по часам, дням, дням недели, неделям, месяцам и годам. С помощью GeoPandas выполнена пространственная привязка каждого детектора к ближайшему отрезку транспортного графа с сохранением edge_id и расстояния до него.

Результат: рассчитанные агрегаты и таблица соответствия detector_id → edge_id загружены в ClickHouse. Полученная структура подготовлена для дальнейшего сопоставления фактических данных детекторов с результатами транспортного моделирования.
